Cow Behavior Detection is a computer vision project for identifying and classifying cow activities from video data.

## Repository structure

- `Cow_Behavior_Detection.ipynb`  
  Jupyter notebook exported from Kaggle and included in this repository.

## About the Kaggle upload

The Jupyter notebook file is included in the repository with the `.ipynb` extension so GitHub will render it with formatting and outputs.

## Getting started

1. Clone the repository:

```bash
git clone https://github.com/precious-05/cow_behavior_detection.git
cd cow_behavior_detection
```

2. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```
